# answerfield

answerfield ist eine typisierte, deklarativ-reaktive Sprache für digitale Assessments: Aufgaben, Testhefte und ihre
Kodierung in einer Quelle, ausgeführt von einer Runtime im Browser.

- **Jetzt ausprobieren:** [answerfield Playground](https://answerfield.github.io/playground/)
- **Wie nutze ich answerfield?** [answerfield Dokumentation](https://answerfield.github.io/writing-items)
- **Warum answerfield?** [answerfield.de](https://answerfield.de)

## Repositories

| Repository | Inhalt |
|---|---|
| [af-format](https://github.com/answerfield/af-format) | Bundle-Format, Auswertung der Ausdrücke, Konformitätsfälle |
| [af-language](https://github.com/answerfield/af-language) | Grammatik, Sprachdienste, Compiler und Standardbibliothek |
| [af-runtime](https://github.com/answerfield/af-runtime) | Runtime, Web Components, Player und Übungsmodus |
| [af-cli](https://github.com/answerfield/af-cli) | Kommandozeile `af`: prüfen, bauen, IQB-Import, PDF-Export |
| [af-web-assessment](https://github.com/answerfield/af-web-assessment) | Angular-Wrapper und Beispiel-App für die Testdurchführung |
| [af-studio](https://github.com/answerfield/af-studio) | Erweiterung für VS Code, Designer, Playground und Beispiele |

Die Pakete liegen als Dateien an den Releases des jeweiligen Repositorys.
